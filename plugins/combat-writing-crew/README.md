# combat-writing-crew

The Combat Writing™ add-on. Placeholder until part 5 of the build (see PLAN.md at the repository root).

When built, this folder holds a local MCP server that sends each seat's packet to other companies' models on your own API keys, so the crew can be more than one company's models. It is installed from this repository as Learning Producers' own marketplace and is never listed in the Claude plugin directory. Keys are never stored in a file.
