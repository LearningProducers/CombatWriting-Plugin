# Support: the Combat Writing plugin and its add-on

For a question, a problem with an install, or a privacy or security concern, write to support@learningproducers.com.

A bug report or a question is also welcome as an issue on this repository: https://github.com/LearningProducers/CombatWriting-Plugin/issues. An issue is public. Send a security concern by mail, not as an issue.

Never send an API key, in a mail or in an issue. A run's `log.jsonl` and `record.md` hold your draft and the seats' answers: send them only if you choose to.

What the two plugins send, store and read is on the privacy page, `PRIVACY.md` in this repository.

Combat Writing is made by Learning Producers Inc. It is not made, reviewed or endorsed by Anthropic.
